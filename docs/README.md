# Documentação do QuotaDock

O QuotaDock acompanha as quotas das contas usadas no OpenCode. Estes guias descrevem o aplicativo publicado na série 0.3, incluindo seus requisitos e o significado das fontes.

## Usar o aplicativo

1. [Instalação e atualização](INSTALLATION.md): instalador, versão portátil, requisitos e SHA-256.
2. [Contas e configurações](CONFIGURATION.md): Google, OpenAI, bandeja, fixação e atualização.
3. [Fontes de quota](PROVIDERS.md): o que cada saldo mede e como interpretar uma leitura anterior.
4. [Solução de problemas e FAQ](TROUBLESHOOTING.md): problemas de login, conexão e janela.
5. [Privacidade](PRIVACY.md): dados locais, credenciais, rede e imagens.

- [Releases](RELEASING.md): versão, pacotes, checksums e publicação segura.
