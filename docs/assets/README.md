# Imagens da documentação

| Arquivo | Uso |
|---|---|
| `quotadock-opencode.png` | Mostra o monitor ao lado do OpenCode, seu contexto principal |
| `quotadock-desktop.png` | Mostra o painel na borda direita da área de trabalho |

As imagens derivam dos prints fornecidos e autorizados pelo autor do projeto. Receberam edição visual por imagem gerada para remover rótulos de e-mail, identificações de projetos e o relógio da barra de tarefas. A edição serve à privacidade e não é evidência pixel a pixel de uma execução.

As quotas são ilustrativas de uma captura; não representam valores padrão, cotas fixas, benchmark ou resultado esperado de um teste. As marcas e interfaces de terceiros não são propriedade do QuotaDock.

Para substituir as imagens, use uma captura sem credenciais, e-mails, IDs, nomes privados de projetos ou URLs de callback. Nunca publique os originais privados como arquivos auxiliares.
